# P10 worker report: non-agent development harness and tool surface

Status: done. Date: 2026-10-02.

## Files

- `tools/session.py`: `ToolSession`, the run-scoped tool surface. A model passes a
  `camera_id`; the session holds the manifest, frames and observations, so nothing has
  to be echoed back through a call. A camera that is not visible (including the
  withheld one) gets a `not_visible` error that lists the allowed ids, never the
  requested id. `tool_call_error` validates a call against its `$defs` entry, so a small
  model gets the field-level error rather than a bare `oneOf` failure.
  `rejection_error` is the exact `tool.completed` error for an invalid call.
- `contracts/tools.schema.json`: the call contract. Args and results for
  `sample_video`, `inspect_camera`, `correlate_observations`, `triangulate_region`,
  `reason_hypothesis`, `get_supporting_frames`, `submit_hypothesis`, each with a
  description.
- `harness/dev_sequence.py`, `harness/README.md`: one fixed call order over the session.
  It announces `harness: "dev-sequence"`, `agent: false` in `orchestrator.started`, and
  has no planner, policy, registry or system prompt.
- `apps/api/services/**`: every API run goes through the harness. `FixtureReplay` is
  deleted; fixture mode is a model profile, not a separate path.
- Tests: `tests/integration/harness/` (`test_dev_sequence.py`, `test_tool_session.py`,
  `test_submit_and_frames.py`, `conftest.py`).
