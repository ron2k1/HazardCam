## Props P11 must feed

`OpsConsole` (`src/components/ops/ops-console.tsx`) is the only component P11 needs to mount; it wires every panel itself.

```ts
interface OpsConsoleProps {
  scenarios: readonly ScenarioSummary[];          // GET /api/scenarios -> .scenarios
  scenario: PublicScenario | null;                // GET /api/scenarios/{id}
  view: RunView;                                  // SSE reducer state
  onScenarioChange: (scenarioId: string) => void;
  onRun: () => void;                              // POST /api/runs, then EventSource(apiUrl(events_url))
  profiles: readonly string[];                    // fixture, lite-local, full-local, remote16gb, gb10
  profile: string;
  onProfileChange?: (profile: string) => void;
  health: ModelsHealth | null;                    // GET /api/models/health?profile=
  apiStatus: "online" | "offline" | "checking" | "mock";  // from GET /healthz
  apiDetail?: string | null;                      // e.g. version or failing dependencies
  healthExtra?: readonly HealthRow[];             // event day: NemoClaw / OpenShell / OpenClaw rows
  judge: JudgeGroundTruth | null;                 // GET /api/judge/scenarios/{id}, reveal action only
  groundTruthRevealed: boolean;
  onRevealGroundTruth?: () => void;
  onHideGroundTruth?: () => void;
  sourceLabel?: string | null;
  noSignalNote?: string;
  onSeek?: (cameraId: string, scenarioT: number) => void;  // telemetry only; seeking is internal
}

interface HealthRow { key: string; label: string; value: string;
  status: HealthStatus; detail?: string | null }
```

SSE reduction:
- start from `EMPTY_RUN_VIEW`
- on each message: `const env = parseEnvelope(e.data); if (env) view = applyEvent(view, env);`
- use `onmessage` only, because the API sends no `event:` field
- the reducer drops other run ids and `seq <= lastSeq`, so `Last-Event-ID` replays are safe

Media URLs are passed through `apiUrl()`. They are requested only when `media_available` / `video_available` is true.

Panel props, for reuse outside `OpsConsole`:
- `CameraTile {camera: PublicCamera; slot: number; src: string|null; run?: CameraRunState|null; seek?: {t, nonce}|null; highlighted?; noSignalNote?}`
- `GroundTruthTile {judge: JudgeGroundTruth|null; src: string|null; revealed: boolean; canReveal: boolean; onReveal?; onHide?}`
- `EvidenceTimeline {cameras; items: TimelineItem[]; clusters; duration: number; samples?; selectedId?; onSeek(cameraId, t); onSelect?(id|null)}`
- `BlindZonePlan {cameras; zones; candidates; rays; groundTruth?; activeEvidenceIds?: ReadonlySet<string>; highlightCameraId?}`

## Assumptions

- `contracts.ts` mirrors the API as P03 actually implemented it, not the earlier draft. Checked again against P03's exact JSON dump:
  - `{scenarios: [...]}` wrapper; items are full `PublicScenario` (selector uses `id`/`title`/`duration_seconds`; camera count comes from `cameras.length`)
  - `media_url` (always a string) / `media_available`
  - public `provenance: PublicProvenance`, always an object (possibly `{}`) holding only the 11 `PUBLIC_PROVENANCE_KEYS` with string values. The key list is identical to P03's Python tuple, same order. The mock applies the same filter as `_provenance_summary`.
  - judge `provenance: Record<string, unknown>`: the full manifest object, or `{}`, never null
  - `ground_truth_camera.video_url` / `video_available`
  - `ModelsHealth {profile, mode, source, status, perception, reasoning}`
  - role status `fixture|unconfigured|unreachable|http_error|ok`, `reachable: boolean|null`
  - `model_listed: boolean|null`. `null` is P03 `_model_listed`'s return when the `/models` body is not JSON, lists no ids, or no model is set.
- `/ops` currently renders `OpsMock`. It replays `contracts/examples` through the live reducer with no network, and is labelled "MOCK · CONTRACTS/EXAMPLES · ILLUSTRATIVE" on screen.
  - Mock latencies are illustrative.
  - Mock media is `media_available: false`, so tiles show NO SIGNAL rather than requesting a 404.
  - Mock health is fixture-shaped.
- The trace harness label comes from the run's `harness` field. P03's temporary executor reports `fixture-replay`, which renders as "FIXTURE-REPLAY · NON-AGENT". The dev sequence renders as "DEV SEQUENCE · NON-AGENT".

## Deviations

- Camera tiles fill the available height and letterbox video (`object-contain`) instead of using a fixed `aspect-video`, so the camera grid and timeline fit 900px without dead space.
- The trace shows time relative to run start (`+1.98S`), with the wall-clock UTC time on hover, instead of absolute timestamps.
- New optional props were added after the first design: `TracePanel.startedAt`, `OpsConsole.apiDetail`, `StackHealthPanel.api.detail`.
- Number Ticker uses a faster spring (34/260) than upstream (60/100). The upstream spring takes about 3 s to settle, and a screenshot caught 0.71 for a 0.74 value.
- `clsx`, `tailwind-merge` and `lucide-react` were removed because nothing imported them.
- Mock profile ids were corrected from `lite`/`full` to the `config/models` names, since the old ids would get a 422 from P03.
- `contracts.ts` is 462 lines, over the advisory size hint. It stays one file because it is the single schema mirror.
