# P12 worker report: evaluation manifest and scoring harness

Status: done. Date: 2026-10-02.

## Files

- `eval/SCORING.md`: the rules, committed (c2087c2) before any run was scored, with a
  dated Clarifications section added after the first two runs. Each clarification
  takes the stricter reading and changes no recorded number.
- `eval/scoring.py`: per-scenario scoring against `data/prepared/<id>/expected.json`.
  Class by accepted-label sets; region only for event claims;
  a GT leak or a failed run is wrong everywhere.
- `eval/summary.py`: Wilson 95% intervals, constant baselines (every event type answered
  for all 22 scenarios; the best is reported, ties going to `unknown`), the two verdicts
  `pipeline_ok` and `beats_constant_baselines`, and `SUMMARY.md`.
- `eval/tool_probe.py`, `scripts/eval/probe_tool_calls.py`: the single-turn tool-call
  probe (judge-side; event-day code may not import it).
- `scripts/eval/run_eval.py`: runs the harness on every manifest scenario and writes
  `artifacts/eval/<profile>/{scenarios.json,summary.json,SUMMARY.md}`, then rebuilds
  `artifacts/eval/summary.json` and `COMPARISON.md`.
- `data/eval/manifest.json`: 22 scenarios (8 positive, 7 negative, 7 ambiguous).
- Tests: `tests/unit/eval/` (60), `tests/integration/eval/test_run_eval.py` (2).

Decision accuracy alone would flatter a model that never commits: always answering
`unknown` scores 14/22, because negatives and ambiguous scenarios accept abstention. So
the only verdicts are `pipeline_ok` and `beats_constant_baselines`, and neither model
pair beats the baselines. Region acceptance is 0 for every run because the accepted
zone lies outside every visible field of view (see `artifacts/model/MODEL_BENCHMARK.md`).
