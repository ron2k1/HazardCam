# 21st Component Plan

Use 21st to accelerate polish, not to dictate architecture.

## Search/install targets
1. `elixr` / spiral or geometric hero motion for landing/inference transition
2. `animated hud targeting` for blind-zone/FOV visualization
3. `agent trace` or streaming execution trace
4. `system monitor` / telemetry blocks

Normalize imported code to project tokens and square-corner theme. Avoid installing many animation runtimes. Prefer one animation stack after the first component lands.

## Offline rule

All selected component source and dependencies must be installed and lockfile-resolved before the final judged run. No runtime requests to 21st.dev.
