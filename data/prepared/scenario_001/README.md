# Scenario 001 expected files

Place prepared local files here:
- `cam_a.mp4`
- `cam_b.mp4`
- `cam_c.mp4`
- `hidden_ground_truth.mp4`
- optional `cameras.json`
- optional `expected.json`

The ground-truth clip is for the judge UI only and must be filtered from agent/model access.

These files are generated by `scripts/data/prepare_scenario.py` from MEVA (CC BY 4.0). The `*.mp4` files are
gitignored. Recreate them with `scripts/data/fetch_meva.py` + `prepare_scenario.py` (see `docs/DATA_SOURCES.md`)
or copy them from the offline bundle. `expected.json` and `evidence/` are judge-only.
